## Expense Tracker


<p>Front End app for managing incomes and expenses built with <b>React</b> and <b>CSS</b></p>
  
![Expense Tracker Gif](https://i.imgur.com/uoYfSOq.gif)
<p>Users can add or remove transactions, track income, expenses, and total balance, as well as view all transactions in the history.</p>
<p>This app was inspired by a <a href="https://www.youtube.com/@TraversyMedia">Traversy Media</a> MERN Stack tutorial. Since it's such a simple app, I chose not to implement a back-end at the time - but I might come back to this in the future though. </p>
